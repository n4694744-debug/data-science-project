# Education, Salary and Working Hours Analysis

## Research Question

How does educational attainment influence annual salary and weekly working hours?

## Dataset

The dataset used in this project is age_salary_hours.csv provided for educational purposes.

The dataset includes:

- Education
- Age
- Annual Salary
- Weekly Hours

## Methods and Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Squarify
- Jupyter Notebook

## Key Findings

The treemap visualization shows the distribution of education levels in the dataset.

The violin plots indicate that higher levels of education are generally associated with higher salary distributions.

Differences in weekly working hours can also be observed across education groups.

## Limitation

The dataset is limited in size and does not include all factors that may affect salary and working hours.
